Route 53 cost optimization

Use alias records to eliminate query charges
Any query that resolves to an alias record pointing at an AWS resource — Elastic Load Balancer, CloudFront distribution, S3 static website, API Gateway endpoint, Elastic Beanstalk — is free. Replace A records or CNAME records pointing at AWS resources with alias records. For high-traffic applications this can eliminate the majority of DNS query costs.

Consolidate hosted zones where possible
Each hosted zone costs $0.50/month even if it serves zero traffic. If you have dev/staging zones that mirror production, consider removing them when not in use. After 25 zones the price drops to $0.10/month, but the first 25 at $0.50 each add up to $12.50/month in zone fees alone.

Traffic Policy records are expensive for simple use cases
Traffic Policy records cost $50/month each — designed for complex multi-region failover with visual policy editor. For simple failover between two endpoints, a standard failover routing policy with a health check costs $1/month ($0.50 health check + $0.50/M queries) instead of $50/month. Only use Traffic Policies when you need complex routing logic across 3+ endpoints.

Advanced routing query volume
Latency, geolocation, failover, and IP-based routing queries cost $0.60/million — 50% more than standard routing. For internal services where latency-based routing between two regions adds marginal benefit, weighted routing ($0.40/M) or alias records (free) may be sufficient.
